# MC Seed Toolkit · Terms & Privacy Policy

Version v1 · updated 2026-09-27

You will see this once on first run. Agree once and you will not be asked again.
Plain words on purpose — no legalese.

---

## 1. What this tool is

A **client-side only** Minecraft toolkit that:

1. Recovers a world seed from a **server map you downloaded yourself**
2. Turns that seed into coordinates for structures (ocean monuments / end cities /
   strongholds / slime chunks …)
3. Ships two game mods: a recorder and a world downloader

It **never connects to the server, needs no OP rights and does not modify the game**.
All the work happens on your own computer.

---

## 2. The part that is on you

1. **Server rules are your business.** Many servers explicitly ban "map download"
   and "seed cracking". Check before you use it. The tool does not judge and does
   not decide for you.
2. **Do not use it against other people.** The coordinates and the seed are for
   your own play on that server.
3. **Correctness depends on the server.** If the server changed world generation
   (custom terrain, datapacks), this method does not apply. The tool will tell you
   so, but it cannot know your specific setup.

## 3. Privacy: what we collect and what we never collect

### By default: nothing is uploaded

The tool itself is **offline** (except for the update check below). Your world
seed, coordinate records and downloaded saves live only in `.mc-tool.json` and
the `记录/` folder on your own computer.

### Update check: once per start, just to see if there is a new version

On startup it fetches a manifest: GitHub first
(`github.com/etyui508/mc-seed-toolkit`), falling back to
`mcdownload.bony-doorframe-shortly.top`. Both are only asked "what is the latest
version" — no data of yours is uploaded.

- What is sent: **your tool version number only** (in the User-Agent)
- What the server can see: your IP and the time — every website sees that
- To keep it open: it still works fine with networking blocked
- To switch it off: set `MC_NO_UPDATE=1` before starting

### Diagnostics log: written to your own computer only

The tool writes a run log to `记录/日志.txt` (version, OS, Python/Java version,
which menu entries you used, query parameters and result counts, tracebacks).

**Seeds, save paths and user names are redacted before they are ever written**
(replaced with `<种子>` / `<路径>` / `<用户>`), so the file is safe to send to
the author as-is.

### Feedback: if you do not press send, nothing leaves your machine

When you pick `5  Send feedback` from the main menu, the tool submits **your
description + contact info (if you filled it in) + the log** to the feedback
site `mcseek.bony-doorframe-shortly.top`.

- This is the **only** place that ever sends a log, and it asks for your
  confirmation first
- To bundle it locally without uploading: set `MC_FEEDBACK_NO_UPLOAD=1` and it
  writes `记录/反馈包-<time>.zip` that you can hand over however you like
- The feedback site records submit time, your IP and client version to prevent
  spam and to help debugging
- Feedback is stored on the author's own server, used for bug fixing only — never
  published, never sold

### What we do not do

No account credentials, no reading your chat logs, no scanning other files on
your computer, no handing your data to third parties.

## 5. What you may and may not do

**Allowed**: use it yourself, give it to friends, modify the code (the Java/C
sources and the structure modules ship in the package), send improvements back.

**Not allowed**: passing on a whole folder that still contains `.mc-tool.json`
(it holds your seed). Delete it first, or pack the folder with
`app/make-zip.py`, which excludes it automatically.
