# MC 种子工具包 · 用户协议与隐私政策

版本 v1 · 更新于 2026-09-27

第一次运行工具时会让你看一遍，同意之后就不再打扰。这个文档是给自己人看的，
所以尽量说人话，不绕弯子。

---

## 一、这个工具是什么

一套**纯客户端**的 Minecraft 工具：

1. 从你**自己下载的服务器地图**里，反推出世界种子
2. 用种子算出各种结构（海底神殿 / 末地城 / 要塞 / 史莱姆区块…）的坐标
3. 附带记录模组和地图下载器两个游戏 mod

它**不连服务器、不用 OP、不改游戏**，所有计算都在你自己的电脑上完成。

---

## 二、你需要自己承担的部分

这部分说清楚了，用起来才踏实：

1. **服规是你自己的事**。很多服务器把"下载地图""破种子"写进了规则，
   用之前请自己看一眼。工具不判断、也不替你决定。
2. **别拿它去搞别人**。算出来的坐标、种子是给你自己在这台服务器上玩用的。
3. **结果对不对，取决于服务器**。如果这个服改过世界生成（自定义地形、数据包），
   这套方法不适用，工具会提示你，但不会知道你那边的具体情况。

## 三、隐私：我们收什么、不收什么

### 默认情况下：什么都不上传

工具本体**不联网**（除了下面说的自动更新）。你的世界种子、坐标记录、
下载的存档，全部只存在你电脑上的 `.mc-tool.json` 和 `记录/` 文件夹里。

### 自动更新：每次启动会问一下有没有新版

启动时它会连 `mcdownload.bony-doorframe-shortly.top` 拿一个清单文件。

- 传过去的东西：**只有你的工具版本号**（放在 User-Agent 里）
- 服务器能看到的：你的 IP、时间 —— 任何网站都能看到这些
- 不想让它联网：启动前设 `MC_NO_UPDATE=1`

### 诊断日志：只写在你自己的电脑上

工具会往 `记录/日志.txt` 写运行日志（版本、系统、Python/Java 版本、
你在菜单里点了什么、查询参数和结果条数、报错堆栈）。

**日志里的种子、存档路径、用户名在写进去之前就已经打码了**
（替换成 `<种子>` / `<路径>` / `<用户>`），所以可以直接发给作者。

### 反馈：你不点，就不会发出去

主菜单选 `5 反馈问题` 时，工具会把**你填的描述 + 联系方式（如果你填了）+ 日志**
提交到反馈站 `mcseek.bony-doorframe-shortly.top`。

- 这是**唯一**会把日志发出去的地方，而且需要你确认
- 想只打包不上传：设 `MC_FEEDBACK_NO_UPLOAD=1`，它会生成
  `记录/反馈包-<时间>.zip`，你自己决定发给谁
- 反馈站会记录提交时间、你的 IP 和浏览器/工具版本，用来防刷和排查
- 反馈存在作者自己的服务器上，只用来修 bug，不会公开、不会卖

### 我们不会做的事

不收集你的账号密码、不读你的聊天记录、不扫描你电脑上的其他文件、
不把你的数据给第三方。

## 四、免责

- 这是个**学生作品**，免费给你用，不提供任何担保。算错了、导出错了、
  因为用了它被服务器处理了 —— 作者不承担责任。
- 更新是自动的。虽然更新包有**离线签名**保护（被篡改会拒绝安装），
  但如果你把工具放在自己不确定安全的地方，风险要自己评估。
- 工具可能随时更新、改功能、停服，不另行通知。

---

## 五、你能做和不能做的

**可以**：自己用、给朋友用、改代码（Java/C 源码和结构模块都在包里）、
把改进发回来。

**别**：把带 `.mc-tool.json`（里面有你的种子）的整包发给别人
—— 借人之前删掉它，或者用 `app/make-zip.py` 打包（会自动排除）。
