# 原理与验证记录

## 一、末地柱子只有 16 bit（1.21.10）

反编译 `EndSpikeFeature`（intermediary `class_3310`）：

```java
public static List<Spike> getSpikes(ServerWorld world) {
    Random random = Random.create(world.getSeed());
    long v = random.nextLong() & 65535L;     // ← 只留 16 位
    return CACHE.getUnchecked(v);
}
```

柱子的位置是固定的（半径 42、36° 均分），高度是 `0..9` 的一个洗牌排列，
顶面 `y = 76 + 3h`、底座半径 `2 + h/3`。排列只由 `v` 决定 —— 也就是**全游戏只有 65536 种末地布局**。

所以"量柱子"单独最多给你 16 bit（低 48 位里的一小段），老版本那种纯靠柱子破种子的方法在 1.21 已经废了，
但作为**筛选/验证信号**非常好用。

## 二、客户端能拿到 sha256(种子)

`ServerPlayerEntity.createCommonPlayerSpawnInfo()` 里：

```java
new CommonPlayerSpawnInfo(..., HashUtils.hash(world.getSeed()), ...)
// BiomeAccess.hashSeed(long) = Hashing.sha256().hashLong(seed).asLong()
```

这个值通过 GameJoin / PlayerRespawn 包发给客户端，客户端存在 `World` 的 `BiomeAccess`（私有字段 `field_20641`）里。
记录模组就是反射读它。

不可逆，但它是**完整 64 位种子的指纹**：低 48 位候选不多时，把高 16 位 65536 种全试一遍，
就能把完整种子定死并 100% 校验（sha256 撞车概率约 1/1.8e19）。

## 三、老式 LCG 体系只吃低 48 位

| 数据 | 随机数 | 吃种子的几位 |
| --- | --- | --- |
| 末地柱子 | `Random.create(seed)`（老式 LCG） | 低 48 位 |
| 史莱姆区块 | `ChunkRandom.getSlimeRandom(x,z,seed,987234911L)` | 低 48 位 |
| 结构摆放 | `ChunkRandom.setRegionSeed(seed,rx,rz,salt)` + `RandomSpreadStructurePlacement` | 低 48 位 |
| 地形/群系噪声 | `Xoroshiro128++`（SplitMix64 + 维度 id 哈希） | **全部 64 位** |

结论：**低 48 位就足以精确预测所有原版结构位置**；地形/群系需要完整 64 位（用哈希或群系采样定下来）。

## 六、末地船

船不是独立摆放的结构，而是末地城生成过程中的概率分支：

```java
if (!shipPlaced && random.nextInt(10 - depth) == 0) {
    addPiece(..., new BlockPos(-8 + rand(8), y, -70 + rand(10)), "ship", ...);
}
```

所以要判断"某座城有没有船"，得扫存档里的 `minecraft:dragon_wall_head`（墙上龙首，只在末地船上天然生成）。

## 七、末地城生成器（只用种子就能算船）

**船在哪，光看种子就能算出来** —— 因为整座城的生成过程是确定的，`tools/endcity.c` 就是照着
1.21.10 客户端 `EndCityPieces`（`class_3342` 及内部四个生成器）的字节码逐条复刻的：

| 环节 | 游戏里的样子 | 复刻时的坑 |
| --- | --- | --- |
| 随机数 | `WorldgenRandom.setLargeFeatureSeed(种子, 区块x, 区块z)` | 先按种子种一次、抽两个 `nextLong()`、再异或回去种一次；`nextLong()` 的低 32 位在 Java 里是**按有符号 int 相加**的（差 2³²，写错整条序列全偏） |
| 段的位置 | 新段 = 父段位置 + 用**父段**的朝向把偏移转过去 | 段的"镜像"在 1.21.10 里恒为 NONE（实测所有段的 placement 都是 NONE） |
| 包围盒 | 把模板两个角 `(0,0,0)` 和 `尺寸-1` 转过去取 min/max，再平移到段位置 | 用 `尺寸-1`（含端点），差一格碰撞判定就变 |
| 递归 | 深度 > 8 就不生成；一批新段生成完掷一次 `nextInt()`，这批 `depth` 都设成它 | 只有和**已有段**撞包围盒、且 `depth` 不同，整批才作废（撞了同批不算） |
| 船 | 桥的生成里 `if (!出过船 && nextInt(10 - 深度) == 0)` | 整座城最多一条船；船的 y 用的是 `k`（不是 `k+1`） |

复刻之后 `out/findstruct ship <种子> <区块x> <区块z> ...` 就能直接出结果（菜单 23 用它），
不用下载存档、不用装游戏、不挑版本。
